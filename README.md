# Simple Python Calculator

This is a very simple command-line calculator project built using Python. It is specifically designed to understand and practice core programming concepts.

## 🚀 Features
- Performs basic arithmetic operations: **Addition (+)**, **Subtraction (-)**, **Multiplication (*)**, and **Division (/)**.
- Includes smart validation to prevent division by zero errors (`ZeroDivisionError`).
- Easy-to-use Command-Line Interface (CLI).

## 🛠️ Concepts Covered
This project implements the following fundamental Python topics:
- **Functions (`def`)**: Used to keep the code organized and reusable.
- **Conditional Statements (`if-elif-else`)**: Used to execute the correct operation based on user choice.
- **User Input Handling**: Takes runtime choices and values from the user.
- **Type Casting**: Converts string inputs into numerical `float` data types for calculations.

## 💻 How to Run
1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Run the following command in your terminal:
   ```bash
   python calculator.py
   ```
